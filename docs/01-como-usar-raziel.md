# Cómo Usar Raziel

Raziel es tu asesor comercial. Hablas con él por texto o por voz, y él responde con texto y voz.

## Acceso

Abre la app en tu navegador. Si hay contraseña configurada, ingresas una sola vez y la sesión dura 7 días.

## Interfaz

- **Izquierda:** el avatar de Raziel. Cambia de forma según el contexto.
- **Centro:** el chat. Aquí aparecen tus mensajes y las respuestas.
- **Arriba:** los links a los 9 módulos de documentación generados.
- **Abajo:** el área para escribir o hablar.

## Cómo interactuar

**Por texto:** escribe tu pregunta o instrucción y presiona Enter o el botón de enviar.

**Por voz:** presiona el ícono de micrófono, habla, y cuando termines presiona el botón de enviar (se vuelve rojo mientras graba). Raziel transcribe lo que dices y responde.

**Voz de Raziel:** activa el ícono de sonido en el header para que Raziel te hable. Desactívalo si prefieres solo leer. El botón cuadrado detiene la voz si quieres interrumpirlo.

## Los 9 módulos

Son documentos generados con tu información de negocio. Se abren desde los links del header. Cada uno tiene un botón para exportar a PDF.

| Link | Qué contiene |
|------|-------------|
| Avatar | Perfil de cliente ideal |
| Oferta | Oferta irresistible (Hormozi) |
| Propuesta | Propuesta tecnológica 3 etapas |
| Auditoría | Reporte de seguridad |
| Legal | Contrato, NDA, Privacidad, T&C |
| Contenido | Estrategia de contenido 90 días |
| Docs | Checklist de documentación por proyecto |
| Branding | Identidad de marca completa |
| Business OS | Sistema operativo del negocio |
| CFO | Análisis financiero y pricing |

## Lo que puedes pedirle

Cualquier cosa relacionada con tu negocio: estrategia, finanzas, marketing, operaciones, documentación, arquitectura técnica. No está limitado a los módulos — es un agente conversacional completo.
